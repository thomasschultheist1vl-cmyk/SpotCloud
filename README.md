# SpotCloud

Proyecto web dinamico para Desarrollo de Aplicaciones Web Dinamicas.

Para ejecutarlo:

1. Copiar esta carpeta dentro de `htdocs`.
2. Importar `database/spotcloud.sql` en phpMyAdmin.
3. Configurar usuario y password de MySQL en `app/config/Conexion.php` si hace falta.
4. Abrir `http://localhost/SpotCloud/public/login.php`.
